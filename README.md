# Danish International | Medical Equipment Solutions

A professional, full-stack medical equipment website built with Next.js, Node.js, and TypeScript. Committed to excellence in healthcare solutions globally.

## Project Structure

- `frontend/`: Next.js 14+ application with Tailwind CSS and Framer Motion.
- `backend/`: Node.js/Express server using TypeScript for robust APIs.

## Tech Stack

- **Frontend**: Next.js (App Router), TypeScript, Tailwind CSS, Framer Motion, shadcn/ui.
- **Backend**: Node.js, Express, TypeScript.
- **Iconography**: React Icons.
- **Deployment & SEO**: Optimized for performance and search visibility.

## Getting Started

### Prerequisites

- Node.js 20+
- npm 11+

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Zain-Ali-712/danish-international.git
   ```

2. Install dependencies:
   ```bash
   # Root (for development setup)
   npm install

   # Frontend
   cd frontend
   npm install

   # Backend
   cd ../backend
   npm install
   ```

### Running the Project

- **Frontend**: `cd frontend && npm run dev`
- **Backend**: `cd backend && npm run dev`
